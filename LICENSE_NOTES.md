# LICENSE_NOTES.md — Legal & artistic notice

## Summary
This project is an **original, offline, single-player creature-collection RPG engine**.
It is intended for **private, local use**. It deliberately contains **no intellectual
property owned by Nintendo, Game Freak, or The Pokémon Company** — no sprites, music,
maps, text, logos, dialogue, creature names, move names, type names as trademarked, or
any data extracted from a commercial game.

## What the demo content is
- **Creatures, moves, items, abilities, regions, trainers, quests, dialogue** shipped in
  `data/` are original inventions created for this project. Names are generic
  (e.g. *Emberpup*, *Ember Burst*, *Verdantia*).
- **Graphics** are generated **procedurally at runtime** by the engine (geometric shapes,
  solid-color tiles, simple silhouettes drawn with Godot's 2D primitives). No image files
  are copied from any third party. See `scripts/core/placeholder_gfx.gd`.
- **Audio** placeholders are generated tones or silence; no third-party audio is bundled.

## Your responsibility as a user
- The engine is designed so you can add **your own legally-obtained** content by dropping
  files into `data/` and `assets/`. Do **not** add copyrighted assets you do not have the
  right to use.
- Do not use this project to distribute copyrighted material.
- No copy-protection is circumvented and no commercial ROM/asset is read by this project.
